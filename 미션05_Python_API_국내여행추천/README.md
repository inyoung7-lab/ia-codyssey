# 국내 여행지 추천 프로그램

Python과 외부 API를 활용하여 여행 날짜에 맞는 국내 여행지를 추천하고,
추천 지역의 맛집 정보를 검색한 뒤 최종 여행 리포트를 생성하는 프로그램입니다.

## 1. 프로젝트 개요

사용자가 여행 날짜를 입력하면 다음 과정을 자동으로 수행합니다.

1. 입력한 날짜 형식 검증
2. Gemini API를 이용한 국내 여행지 추천
3. 추천 지역의 날씨 특징 및 행사 정보 생성
4. Kakao Local API를 이용한 주변 맛집 검색
5. 수집한 정보를 JSON 형식으로 저장
6. 최종 국내 여행 추천 리포트를 Markdown 파일로 생성

전체적인 흐름은 다음과 같습니다.

`여행 날짜 입력 → 날짜 검증 → Gemini 여행지 추천 → Kakao 맛집 검색 → JSON 저장 → Markdown 리포트 생성`

## 3. 주요 파일

### `travel_planner.py`

프로젝트의 메인 프로그램입니다.

여행 날짜를 입력받아 Gemini API와 Kakao Local API를 호출하고,
최종 결과를 JSON 및 Markdown 파일로 저장합니다.

### `gemini_test.py`

Gemini API가 정상적으로 연결되는지 확인하기 위한 테스트 프로그램입니다.

### `.env`

API 키를 저장하는 환경 변수 파일입니다.

보안을 위해 GitHub에는 업로드하지 않습니다.

### `.gitignore`

`.env`, Python 캐시 파일 및 실행 결과 폴더 등
Git에 포함하지 않을 파일을 관리합니다.

### `results/`

프로그램 실행 후 생성되는 결과 파일이 저장됩니다.

예시:

- `2026-10-15_raw.json`
- `2026-10-15_travel_plan.md`

### `evidence/`

프로젝트 구현 및 테스트 과정의 증빙 이미지가 저장됩니다.

## 9. 보너스 과제

### 9.1 복수 지역 추천

기본 요구사항에서는 하나의 국내 여행지를 추천하도록 되어 있지만,
보너스 과제를 수행하기 위해 LLM이 한 번의 실행에서
3개의 여행 지역을 추천하도록 기능을 확장하였다.

추천 결과는 각 지역별로 다음 정보를 포함하도록 구조화하였다.

- 추천 지역
- 날씨 요약
- 행사/축제
- 추천 이유

추천된 각 지역에 대해 반복문을 사용하여
Kakao Local API로 맛집을 각각 검색하도록 구현하였다.

실행 예시:

- 경주시
- 전주시
- 순천시

각 지역별로 최대 5개의 맛집을 검색하며,
검색 결과에는 다음 정보를 저장한다.

- 맛집 이름
- 주소
- 카테고리
- Kakao Map URL
- 좌표(x, y)

이를 통해 단일 지역을 처리하는 프로그램에서
여러 지역을 반복적으로 처리하는 프로그램으로 확장하였다.

### 9.2 결과 캐싱

동일한 날짜로 프로그램을 다시 실행할 경우
이미 생성된 원본 JSON 파일이 존재하는지 확인하도록 구현하였다.

예를 들어 다음 파일이 이미 존재한다면:

`results/2026-10-15_raw.json`

기존 데이터를 캐시(Cache)로 사용한다.

캐시가 발견되면 다음 API 호출을 다시 수행하지 않는다.

- 여행지 추천을 위한 LLM API 호출
- Kakao Local API 맛집 검색

실행 시 다음과 같은 메시지가 출력된다.

```text
[CACHE] 기존 원본 JSON을 발견했습니다.
[CACHE] 여행지 추천 및 Kakao 맛집 API 호출을 건너뜁니다.
```
