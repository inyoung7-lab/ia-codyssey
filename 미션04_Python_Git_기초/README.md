# 프롬프트 관리자

## 프로젝트 소개

프롬프트 관리자는 Python의 리스트와 딕셔너리를 활용하여 다양한 프롬프트를 관리하는 콘솔 프로그램입니다. 제목, 내용, 카테고리, 즐겨찾기 상태를 기준으로 프롬프트를 등록하고 조회할 수 있습니다.

프로그램 시작 시 다음 주제의 기본 프롬프트 데이터 3개가 등록되어 있습니다.

- LLM 프롬프트 엔지니어링 관련 텍스트 생성 프롬프트
- EchoLens 광고 제작 관련 이미지 생성 프롬프트
- AI 뉴스 관련 자동화 프롬프트

## 실행 환경

- Python 3.10 이상

## 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python main.py
```

## 기능 설명

1. 프롬프트 추가: 제목, 내용, 카테고리를 입력하여 새 프롬프트를 등록합니다. 미리 정의된 카테고리를 선택하거나 사용자가 카테고리를 직접 입력할 수 있습니다.
2. 프롬프트 목록: 등록된 모든 프롬프트의 기본 정보를 확인합니다.
3. 카테고리별 조회: 선택한 카테고리에 속한 프롬프트만 확인합니다.
4. 프롬프트 검색: 제목 또는 내용에 검색어가 포함된 프롬프트를 찾습니다.
5. 프롬프트 상세 보기: 선택한 프롬프트의 제목, 내용, 카테고리, 즐겨찾기 상태를 확인합니다. 상세 조회할 때 조회수가 1 증가합니다.
6. 즐겨찾기 관리: 선택한 프롬프트를 즐겨찾기에 추가하거나 즐겨찾기에서 제거합니다.
7. 즐겨찾기 목록: 즐겨찾기로 지정된 프롬프트만 확인합니다.
8. JSON 저장: 현재 프롬프트 데이터를 `prompts.json` 파일에 저장합니다.
9. JSON 불러오기: `prompts.json` 파일에 저장된 프롬프트 데이터를 불러옵니다.
10. 카테고리별 Markdown 내보내기: 전체 프롬프트를 카테고리별 Markdown 파일로 내보냅니다. 실행하면 `exports` 폴더에 카테고리별 `.md` 파일이 생성됩니다.
11. 프롬프트 수정: 선택한 프롬프트의 제목, 내용, 카테고리를 수정합니다.
12. 프롬프트 삭제: 선택한 프롬프트를 확인 후 삭제합니다.
13. 조회수 TOP 목록: 프롬프트를 조회수가 높은 순서대로 확인합니다.

## 프롬프트 카테고리

프롬프트를 추가할 때 다음 기본 카테고리 중 하나를 선택할 수 있습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

또한 "직접 입력"을 선택하면 사용자가 원하는 카테고리명을 직접 입력할 수 있습니다.

## 데이터 유지 방식

프로그램 실행 중 추가하거나 변경한 데이터는 리스트에 유지됩니다. JSON 저장 기능을 사용하면 데이터를 `prompts.json` 파일에 저장할 수 있고, JSON 불러오기 기능으로 저장된 데이터를 다시 불러올 수 있습니다.

## 보너스 기능

- 보너스 1: JSON 저장 및 불러오기, 카테고리별 Markdown 내보내기
- 보너스 2: 프롬프트 수정 및 삭제, 조회수 기록, 조회수 TOP 목록

## Git 브랜치 활용

프롬프트 목록 기능은 별도의 Git 브랜치에서 개발한 뒤 `main` 브랜치에 병합(merge)했습니다.
