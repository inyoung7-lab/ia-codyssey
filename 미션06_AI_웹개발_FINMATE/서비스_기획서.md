# FINMATE AI 서비스 기획서

## 1. 서비스 개요

### 서비스명

FINMATE AI

### 서비스 한 줄 소개

기업명을 입력하면 AI가 기업의 사업 내용, 강점과 위험 요소를 투자 초보자에게 쉽게 설명하는 투자 학습 웹 서비스

### 서비스 목적

주식 투자를 처음 시작하는 사용자는 기업의 사업 구조와 투자 정보를 이해하기 어려울 수 있다. FINMATE AI는 사용자가 관심 기업의 이름을 입력하면 Gemini가 기업 소개, 주요 사업, 강점, 위험 요소 등을 쉬운 한국어로 설명해 기업 학습의 시작점을 제공한다.

본 서비스는 특정 주식의 매수·매도를 지시하거나 수익을 보장하는 투자 자문 서비스가 아니다. AI 분석은 투자 학습 및 정보 제공 목적으로만 사용한다.

## 2. 타겟 사용자

- 주식 투자를 처음 시작한 초보 투자자
- 기업 분석이 어렵게 느껴지는 사용자
- 투자 기초 개념을 공부하고 싶은 사용자
- 관심 기업의 사업, 강점, 위험 요소를 간단히 파악하고 싶은 사용자

FINMATE AI는 하나의 HTML 페이지 안에서 상단 메뉴와 버튼으로 각 섹션에 이동하는 구조이다.

### 3.1 홈

- FINMATE AI 서비스명과 핵심 메시지
- 투자 초보자를 위한 서비스 소개
- AI 기업 분석 섹션으로 이동하는 시작 버튼

### 3.2 투자 학습

다음 세 가지 기초 주제를 정적 카드로 간단히 소개한다.

- 주식이란?
- PER · PBR
- 투자 위험

별도의 퀴즈, 진도 관리 또는 상세 학습 페이지는 구현하지 않았다.

### 3.3 AI 기업 분석

사용자가 기업명을 입력하면 AI가 초보자도 이해하기 쉬운 형태로 해당 기업을 설명한다.

입력 예시:

- 삼성전자

- NVIDIA

출력 구성:

- 기업 소개
- 주요 사업
- 강점
- 위험 요소
- 초보자 한줄 정리

### 3.4 서비스 소개

- FINMATE AI의 투자 학습 목적
- AI 답변이 투자 참고 및 학습용이라는 유의 문구

### 3.5 공통 UI

- 상단 메뉴의 부드러운 섹션 이동

## 4. AI 기능 설계

### 기능명

AI 기업 분석

### 사용자 가치

기업 분석을 처음 접하는 사용자가 복잡한 자료를 읽기 전에 관심 기업이 어떤 사업을 하고 어떤 강점과 위험 요소가 있는지 쉬운 표현으로 파악하도록 돕는다.

### 실제 입력

사용자가 입력하는 값은 **기업명 한 가지**이다. 입력창은 필수이며 최대 길이는 100자이다.

### 처리 과정

1. 사용자가 HTML form에 기업명을 입력하고 `AI 분석` 버튼을 누른다.
2. HTML과 JavaScript가 입력값을 검사한다.
3. JavaScript가 `POST fetch('/api/analyze')`로 `{"company": "기업명"}` JSON을 보낸다.
4. Vercel이 `/api/analyze`를 Python Serverless Function인 `api/analyze.py`로 연결한다.
5. Python이 요청 JSON, 기업명, `GEMINI_API_KEY`를 확인한다.
6. Python이 투자 초보자용 분석 프롬프트로 Gemini API를 호출한다.
7. Gemini가 기업 분석 텍스트를 생성한다.
8. Python이 `company`, `analysis`, `model` 필드가 있는 JSON을 반환한다.
9. JavaScript가 `analysis` 값을 받아 HTML 특수문자를 이스케이프하고 줄바꿈과 굵은 글씨를 변환해 화면에 표시한다.

```text
사용자
  ↓
HTML 기업명 입력
  ↓
JavaScript fetch('/api/analyze')
  ↓
Vercel Serverless Function
  ↓
Python api/analyze.py
  ↓
Gemini API
  ↓
Python JSON 응답
  ↓
JavaScript 결과 처리
  ↓
웹 화면 출력
```

### 출력 기준

Gemini 프롬프트는 기업 소개, 주요 사업, 대표 강점 2~3개, 대표 위험 요소 2~3개, 초보자 한줄 정리를 한국어로 작성하도록 요청한다. 어려운 금융 용어는 쉽게 설명하고, 다음 내용은 생성하지 않도록 제한한다.

- 특정 주식의 매수 또는 매도 권유
- 투자 수익 보장 표현
- 최신 주가나 실시간 재무 정보를 알고 있다는 가정
- 확인되지 않은 숫자

## 5. 입력 검증 및 실패 처리

### 5.1 빈 입력

입력창의 HTML `required` 속성으로 빈 값 제출을 먼저 막고 브라우저의 필수 입력 안내를 표시한다. 공백만 입력하는 경우를 포함해 JavaScript에서도 `trim()` 결과를 확인하며, Python 백엔드도 빈 기업명을 다시 검사한다.

### 5.2 입력 길이

HTML 입력창은 `maxlength="100"`으로 제한한다. JavaScript와 Python에서도 100자를 초과한 기업명을 거부한다.

### 5.3 분석 진행 상태

요청 후 응답을 기다리는 동안 다음 동작을 적용한다.

- 상태 영역: `AI가 기업 정보를 분석하고 있습니다...`
- 결과 영역: 분석 중 안내 문구
- 버튼 비활성화 및 `분석 중...` 표시
- 완료 또는 오류 후 버튼 원상 복구

### 5.4 API 및 네트워크 오류

JavaScript는 오류 원문을 화면에 직접 노출하지 않고 사용자용 한국어 메시지로 변환한다.

- 네트워크 중단 또는 `fetch` 실패: `네트워크 연결 또는 AI 서비스에 문제가 발생했습니다. 잠시 후 다시 시도해주세요.`
- 인증, 사용량 제한, 응답 지연, 서버 오류, 빈 분석 결과, JSON 처리 오류: 상황별 한국어 안내
- 결과 영역: `분석 결과를 불러오지 못했습니다.`

Python 백엔드는 다음 오류에 JSON과 HTTP 상태로 응답한다.

- `GEMINI_API_KEY` 미설정
- 잘못된 요청 JSON
- 빈 기업명 또는 100자 초과
- Gemini 인증, 모델, 사용량 제한, 서버, 네트워크, 시간 초과 오류
- Gemini 응답의 결과 누락 또는 파싱 오류
- 예상하지 못한 서버 오류

## 6. 기술 구성과 역할

### HTML

- 웹페이지의 네 개 주요 섹션 구성
- 기업명 입력 form, 분석 버튼, 상태 및 결과 영역 제공
- `required`, `maxlength`를 이용한 기본 입력 제한

### CSS

- 색상, 타이포그래피, 카드, 버튼, 분석 결과 영역 디자인
- 라이트/다크 모드 스타일
- Media Query를 이용한 모바일 레이아웃
- 로딩, 성공, 오류 상태 색상

### JavaScript

- 메뉴 이동과 테마 전환
- 기업명 검사와 중복 요청 방지
- `fetch('/api/analyze')`를 통한 Python API 호출
- 로딩, 성공, 실패 상태 처리
- AI 분석 결과의 안전한 화면 출력

### Python / Vercel Serverless Functions

- 환경 변수에서 `GEMINI_API_KEY` 확인
- 요청 JSON 및 기업명 검증
- Gemini API 호출과 결과 텍스트 추출
- 성공 또는 오류 JSON 반환

Python은 현재 표준 라이브러리만 사용하므로 별도 패키지 의존성이 없다.

### Gemini API

기업명을 바탕으로 투자 초보자용 기업 분석 내용을 생성한다.

### GitHub / Vercel

- Git과 GitHub: 소스 버전 관리
- Vercel: 정적 프론트엔드와 Python Serverless Function을 Production으로 배포

## 7. 보안 설계

- Gemini API Key를 HTML, CSS, JavaScript 또는 Python 코드에 직접 작성하지 않는다.
- Python은 `os.environ.get("GEMINI_API_KEY")`로 실행 환경의 값을 읽는다.
- 로컬 개발용 Key는 `.env`에서 관리한다.
- `.gitignore`에 `.env`, `.env.local`, `.env.*`를 등록해 Git에 포함되지 않도록 한다.
- 배포용 Key는 Vercel Environment Variables의 Production 환경에서 Sensitive 값으로 관리한다.
- 브라우저는 Gemini에 직접 요청하지 않고 동일 출처의 `/api/analyze`만 호출한다.
- 서버 로그에는 API Key 값을 출력하지 않는다.

이 구조는 브라우저와 공개 저장소에서 실제 API Key가 노출되는 것을 방지한다.

## 8. 반응형 설계 및 확인 범위

CSS Media Query로 다음 동작을 구현했다.

- 900px 이하: 홈 제목 크기와 자간 조정
- 800px 이하: 메뉴 링크 숨김, 학습 카드 1열 배치, 입력창과 분석 버튼 세로 배치
- 600px 이하: 모바일용 홈 제목 크기와 줄 간격 추가 조정

실제 화면 검증은 데스크톱과 Chrome DevTools의 400 × 857 모바일 화면에서 완료했다. 태블릿 전용 실기기 테스트를 완료했다고 주장하지 않는다.

## 9. 배포 계획 및 완료 결과

### 배포 구성

`vercel.json`에서 다음 항목을 구성한다.

- `index.html`, `css/**`, `js/**`, `images/**`: 정적 리소스
- `api/*.py`: Vercel Python Serverless Function
- `/api/analyze`: `/api/analyze.py`로 라우팅

### Production 배포 절차

1. Git/GitHub에서 제출할 소스를 관리한다.
2. Vercel Production Environment Variables에 `GEMINI_API_KEY`를 등록한다.
3. 프로젝트 루트에서 `vercel --prod`를 실행한다.
4. 배포 URL에서 화면과 실제 AI 분석 결과를 확인한다.

### 배포 결과

- 상태: Vercel Production 배포 완료
- URL: <https://finmate-ai-gold.vercel.app>
- 확인 완료: 홈, 투자 학습, AI 분석 입력 화면, Gemini 분석 결과, 빈 입력, 네트워크 오류, 모바일 반응형 화면

## 11. 구현 범위에서 제외된 기능

현재 구현에 포함되지 않은 다음 기능은 서비스 기능으로 주장하지 않는다.

- 주식 종목 추천 또는 매수·매도 판단
- 실시간 주가, 재무제표 또는 뉴스 조회
- 사용자 로그인, 관심 기업 저장, 분석 기록 저장
- 퀴즈, 학습 진도 관리, 별도 상세 학습 페이지
- 분석 결과의 정확성 또는 투자 수익 보장

## 12. 서비스 이용 안내

Gemini가 생성한 분석은 실제 최신 기업 정보와 차이가 있을 수 있다. 사용자는 실제 투자 결정을 내리기 전에 기업의 공식 자료와 최신 정보를 별도로 확인해야 하며, 모든 투자 판단과 책임은 사용자에게 있다.
