# FINMATE AI 서비스 기획서

## 1. 서비스 개요

### 서비스명
FINMATE AI

### 서비스 한 줄 소개
사용자의 투자 목표와 성향을 분석하여 AI가 맞춤형 자산배분 예시와 투자 학습 정보를 제공하는 웹 서비스

### 서비스 목적
투자를 처음 시작하는 사람은 자신의 투자 성향이나 투자 기간에 따라
어떤 방식으로 자산을 배분해야 하는지 판단하기 어려울 수 있다.

FINMATE AI는 사용자가 입력한 투자금, 투자 기간, 투자 성향,
관심 분야 및 투자 목표를 AI가 분석하여 이해하기 쉬운 형태의
자산배분 예시와 위험요인을 제공하는 것을 목적으로 한다.

본 서비스는 실제 금융상품에 대한 매수·매도 지시를 제공하는
투자 자문 서비스가 아니라 투자 학습과 정보 제공을 목적으로 한다.

주요 사용자는 다음과 같다.

- 투자를 처음 시작하는 초보 투자자

## 4. AI 기능 설계

### 기능명
AI 투자 포트폴리오 분석

### 입력

사용자가 웹페이지에서 다음 정보를 입력한다.

- 투자금
- 투자 기간
- 투자 성향
- 관심 분야
- 투자 목표

### 처리 과정

1. 사용자가 웹페이지에서 투자 정보를 입력한다.
2. JavaScript가 입력값을 확인한다.
3. JavaScript의 fetch()를 사용하여 `/api/analyze`로 요청한다.
4. Vercel Serverless Function으로 구현된 Python 백엔드가 요청을 받는다.
5. Python 백엔드가 AI API에 사용자 정보를 전달한다.
6. AI가 투자 학습용 분석 결과를 생성한다.
7. Python 백엔드가 결과를 JSON 형식으로 반환한다.
8. JavaScript가 응답을 받아 웹 화면에 표시한다.

### 출력

AI 분석 결과에는 다음 내용을 포함한다.

- 사용자 투자 성향 요약
- 자산배분 예시
- 자산배분 이유
- 주요 위험요인
- 투자 시 고려할 사항

## 5. 사용자에게 제공하는 가치

FINMATE AI는 복잡한 투자 개념을 초보자도 쉽게 이해할 수 있도록
사용자가 입력한 조건에 맞추어 설명한다.

단순히 동일한 정보를 보여주는 것이 아니라
투자 기간과 위험 성향 등의 입력에 따라 다른 결과를 제공한다.

이를 통해 사용자는 자신의 투자 성향과
자산배분의 기본 개념을 학습할 수 있다.

## 6. 실패 처리 기준

### 빈 입력

필수 입력값이 없을 경우:

"필수 정보를 모두 입력해주세요."

라는 메시지를 화면에 표시하고 API 요청을 보내지 않는다.

### API 오류

AI API 또는 서버에서 오류가 발생한 경우:

"AI 분석 중 문제가 발생했습니다. 잠시 후 다시 시도해주세요."

라는 메시지를 표시한다.

### 응답 지연

AI가 결과를 생성하는 동안:

"AI가 투자 정보를 분석하고 있습니다..."

라는 로딩 메시지를 표시한다.

## 7. 기술 구성

### Frontend

- HTML
- CSS
- JavaScript

HTML은 웹페이지의 구조,
CSS는 디자인과 반응형 화면,
JavaScript는 사용자 입력 처리와 API 통신을 담당한다.

### Backend

- Python
- Vercel Serverless Functions

`api/` 폴더의 Python 함수를 통해 AI API를 호출한다.

### AI

외부 AI API를 Python 백엔드에서 호출하여
사용자 입력에 따른 분석 결과를 생성한다.

### 배포

- GitHub
- Vercel

GitHub에 프로젝트 코드를 저장하고
Vercel과 GitHub 저장소를 연동하여 웹 서비스를 배포한다.

---

## 8. 보안 설계

AI API Key는 HTML, CSS, JavaScript 또는 Python 코드에
직접 작성하지 않는다.

API Key는 환경 변수로 관리하며
로컬 환경과 Vercel 배포 환경에서 각각 설정한다.

이를 통해 GitHub에 코드를 공개하더라도
API Key가 노출되지 않도록 한다.

## 11. 서비스 이용 안내

FINMATE AI가 제공하는 내용은 투자 학습 및 정보 제공을 목적으로 한다.

AI가 생성한 결과는 실제 시장 상황이나 개인의 모든 재무 상황을
반영하지 않을 수 있으며 특정 금융상품의 매수 또는 매도를
지시하는 투자 자문으로 사용하지 않는다.
