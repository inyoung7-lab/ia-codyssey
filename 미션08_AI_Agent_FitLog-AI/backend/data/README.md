# 운동 기록 샘플 데이터

`sample_workout_data.json`은 향후 Firestore 저장 및 운동시간 요약·추세 분석 기능을 테스트하기 위한 JSON 배열입니다. 실제 개인 운동 기록이 아닌 개발·테스트용 합성 데이터이며, 현재 Firebase에 업로드하지 않습니다.

| 필드 | 형식 | 의미 |
| --- | --- | --- |
| `date` | `YYYY-MM-DD` 문자열 | 운동 기록 날짜 |
| `value` | 0 이상의 정수 | 해당 날짜의 총 운동시간. 단위는 분(minutes) |
| `memo` | 문자열 | 운동 종류 및 내용. 휴식일은 `"휴식"` |

- 기간: 2026-05-31부터 2026-09-27까지 연속 120일. 날짜 중복 없이 오래된 순서로 정렬합니다.
- 휴식일은 `value = 0`, `memo = "휴식"`입니다. 운동일에는 웨이트, 복싱, 러닝, 걷기, 스트레칭을 포함합니다.
- 운동 종류, 시간, 휴식일 간격에 변화를 주고 초반보다 후반의 평균 운동시간이 조금 증가하도록 구성했습니다.
- 평균은 휴식일의 0분을 포함한 일평균입니다. 최근 7일은 데이터의 마지막 날짜를 기준으로 2026-09-21~2026-09-27, 이전 7일은 2026-09-14~2026-09-20입니다.
- 최근 7일 평균이 이전 7일보다 높은 증가 사례입니다. 감소·유지 사례는 별도 테스트 데이터가 필요합니다.
